# Third-party binaries

Place portable tooling used by the Auditor here.

## WinSCP (required for FTP/SFTP)

1. Download [WinSCP Portable](https://winscp.net/eng/download.php)
2. Extract `WinSCP.exe` to:

```text
libs/winscp/WinSCP.exe
```

The build may also look under `build/bin/Release/` depending on your layout.
`libs/` binaries are gitignored — only this README is tracked.
