## Column reference

| Column | Meaning |
| --- | --- |
| **Classname** | DayZ type name used in `types.xml` |
| **Tier** | Economy tier (1–11+) assigned by audit / policy |
| **Category** | Economy category (`weapons`, `clothes`, …) |
| **Nominal** | Target count of this item on the map |
| **Min** | Soft floor before restock pressure |
| **Lifetime** | Seconds before despawn when untouched |
| **Restock** | Restock interval (seconds) |
| **Source** | Origin file / mod label from the export |

---

## How this was built

1. Run the Auditor GUI → download / load server XMLs → export.
2. Auditor writes `output/items.csv`.
3. That CSV was formatted into these Markdown grids as a one-time example snapshot.
